## About Me
* B.Sc. in **Data Science and Engineering** from the Technion (2025), then Experis Academy's six-month **C/C++** program (2026).
* I like building small, fast things close to the system: terminal apps in C, sockets, threads, no dependencies when I can help it.
* I live in the terminal on Arch-based Linux with Hyprland. My setup is public: [dotfiles](https://github.com/shalom2552/dotfiles) | [hyprconf](https://github.com/shalom2552/hyprconf) | [nvim](https://github.com/shalom2552/nvim)
* 130+ LeetCode problems solved, mostly in **C++** and **Python**. [Solutions](https://github.com/shalom2552/leetcode)

## Projects

**C and the terminal**
* [tuitris](https://github.com/shalom2552/tuitris): Tetris in the terminal. Pure C, raw ANSI rendering, no ncurses, no heap allocations.
* [wasup](https://github.com/shalom2552/wasup): Multi-client chat over TCP. Single-threaded `poll()` server, up to 64 clients in 16 rooms.
* [blind](https://github.com/shalom2552/blind): Touch-typing practice without leaving the terminal. No AI on this one, only vim.
* [sh25-shl](https://github.com/shalom2552/sh25-shl): My single-header C libraries: unit testing, dynamic array, stack, terminal drawing.
* Also: a [grid strategy game](https://github.com/shalom2552/terminal-minimax-game) against the computer (C99) and [2048](https://github.com/shalom2552/2048) (C++17, still in progress).

**Bigger builds**
* [cdr-processor](https://github.com/shalom2552/cdr-processor): My Experis Academy capstone. Multithreaded C++17 service that ingests call records from files or RabbitMQ into Redis, with crash-safe resume and an HTTP query API. 440 tests in CI.
* [kern-lite](https://github.com/shalom2552/kern-lite): Black-box data logger on STM32 and FreeRTOS, built in a team of 3. My part: the recorder pipeline, SD storage that survives power loss, and the Python ground station.
* [dog-detector](https://github.com/shalom2552/dog-detector): Multi-camera YOLO dog detection on CPU with ONNX Runtime, no PyTorch at runtime. Sends a Telegram alert when a dog stays in a zone you draw. Runs in Docker.

**Tools for my own setup**
* [ptt](https://github.com/shalom2552/ptt): Hold a key, talk, and the words get typed at the cursor. Offline Whisper on the GPU, for Wayland.
* [agent-skills](https://github.com/shalom2552/agent-skills): Skills and plugins I wrote for the coding agents I work with.
